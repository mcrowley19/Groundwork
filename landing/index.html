How it works

There are no public pipe records, so we estimate where the mains are and say how sure we are, street by street.

  1. Find the planned homes

    Planning applications from the last three years, from the national planning database.

  2. Read each application

    A language model pulls out the number of units and whether it's a new build.

  3. Estimate the mains

    Each street gets a confidence level from hydrants, manholes and buildings along it.

  4. Find the gaps

    A development counts as served if an estimated main runs within 50 m.

  5. Route the new pipe

    For the rest, the shortest new network along existing streets that reaches them all.

How sure are we?

Every street gets a confidence level from the evidence along it. The map shows all four, so you can see where the estimate is strong and where it's a guess.
